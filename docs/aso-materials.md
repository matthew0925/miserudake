## 競合分析（2026年8月調査）

同カテゴリで実際にストアに存在する「黒塗り・モザイクで個人情報を隠す」系アプリを調査した。

| アプリ | 訴求の型 | 価格モデル |
|---|---|---|
| 黒塗り＆モザイク - スクショ・写真の個人情報を隠すアプリ | 「透けない黒塗り・復元不可・Exif自動削除」を副題に直書き | 無料＋広告除去IAP(¥500) |
| モザイク・黒塗りで情報を隠すアプリ | 顔・文字・番号を黒塗り／モザイク／ぼかしで隠す汎用ツール | 無料＋IAP |
| 写真モザイク・顔/文字ぼかし・黒塗り・番号消し加工アプリ | 顔・文字ぼかし・黒塗り・番号消しを機能列挙 | 無料＋IAP |
| Radact（顔・文字・QRのワンタップ自動検出＋端末内完結） | 自動検出＋端末内処理をUSP化 | 参考（国内ストア表記は要確認） |

**分かったこと**
- 競合の主戦場は「写真全般の顔・個人情報ぼかし」という汎用ツールで、いずれも無料＋広告除去/機能解放IAPのフリーミアム。**本人確認書類に特化**し、書類種別プリセット（免許証／マイナンバーカード／保険証／パスポート）で「隠すべき項目」まで案内するアプリは見当たらない。
- 「復元不可」「Exif自動削除」「端末内完結」は競合も訴求している定番ポイントであり、これらは前提として押さえた上で、**書類特化・買い切り・サブスクなし**で差別化する。
- 広告除去モデルの競合に対し、本アプリは**広告を最初から出さない**（透かし解除のみの買い切り）ことも安心材料として明記する価値がある。

**この調査を踏まえた方針**
1. アプリ名・サブタイトルで「身分証」に特化していることを最初の3秒で伝える（汎用ぼかしアプリと混同されない）
2. 「復元不可」「Exif自動削除」を機能一覧に明記し、競合と同じ土俵でも見劣りしないようにする
3. 「広告なし・買い切りのみ」を価格訴求スクリーンショットで明確化
4. 書類種別プリセットのガイド機能（本アプリ独自）をスクリーンショット1枚分に格上げ

## 説明文（本文）

```
その身分証の写真、住所まで見えていませんか？

「Sumi」は、本人確認書類を撮影するだけで、隠すべき個人情報を自動で
見つけてマスキングするアプリです。

■ 撮るだけで、隠す場所が分かる
運転免許証、マイナンバーカード、健康保険証、パスポートなどを撮影すると、
住所・生年月日・個人番号・QRコードなど、隠した方がいい場所を自動で検出
します。書類の種類ごとに「よく隠される項目」の目安も確認できます。撮影中は
書類の傾きや枠合わせもその場でガイドするので、綺麗に撮れているか迷いません。

■ 最終確認はあなたの目で
自動検出はあくまで候補。マスキングする場所は指でタップして追加・解除でき、
範囲も自由に調整できます。保存・共有する直前には、加工前後をスライダーで
見比べる最終確認画面が必ず出るので、「隠したつもりが隠れていなかった」を防ぎます。

■ 復元できない黒塗り・モザイク
ぼかし加工と違い、黒塗り・モザイクは元の情報を上書きするため、書き出した
画像を拡大しても元の文字は復元できません。書き出し時にEXIF情報（位置情報
など）も自動で取り除きます。

■ 端末の中だけで完結
撮影した画像は一切サーバーに送信しません。処理はすべてこの端末の中だけで
行われます。アカウント登録も不要です。

■ 広告なし・買い切りのみ
無料版でも全ての機能をお使いいただけます（書き出し画像に控えめな透かしが
入ります）。透かしの解除は、一度のお支払いで完了する買い切り価格です。
広告表示もサブスクリプションもありません。

■ フリマ・単発バイト・賃貸契約に
個人間取引の本人確認、単発バイトの応募、賃貸物件の入居審査など、身分証の
写真を送る場面で、不要な個人情報まで晒してしまうのを防ぎます。
```

1. **フック**：「その身分証の写真、住所まで見えていませんか？」— 無加工の身分証画像に赤丸で不要情報を強調
2. **書類特化の独自性**：書類種別を選ぶと「よく隠す項目」ガイドが出る画面（競合の汎用ぼかしアプリにはない差別化ポイント）

5. **信頼**：「保存前に、もう一度だけ確認」— 加工前後を見比べる最終確認スライダーのUI
6. **価格訴求**：「無料で試せる。広告なし。買い切り¥500、サブスクなし」
